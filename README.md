# your_calendar

The public manual of **MyCalendar**, an Android calendar widget whose settings and looks are changed
by talking to any AI chat ([akinoame1/my_calendare](https://github.com/akinoame1/my_calendare)).

An AI chat asked to change the app should read **[manual/latest/index.md](manual/latest/index.md)**
first: what the app is, every part of the widget by the name its settings use, how to answer, and
every setting the app accepts. Each release has its own copy under `manual/<version>/`, so a message
from a given version of the app can point at exactly what that version accepts.

These pages are generated from the app's own code (`spec/Manual.kt` in my_calendare) and never
edited by hand here.
